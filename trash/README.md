# Local archive

Old versions, unused assets, screenshots, reports and backup ZIPs are moved here instead of deleted. `MOVED_FILES.json` lists their original locations and SHA-256 checksums. Subfolders group `assets/`, `backups/`, `evidence/`, `history/` and `legacy-projects/`.

Only this README is tracked. Archive contents are intentionally ignored by Git so old media, private local records and backup copies are not republished. The original files remain on the machine that performed the cleanup. A fresh clone creates this folder without those local archived files.

Restore an item to its recorded original path if needed; check for newer files before restoring. Nothing in this folder is required to serve, build or test the current portfolio.
